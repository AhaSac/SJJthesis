## 在 VS Code 中编译

1. 用VS Code打开本说明旁的 `sjj22627171.code-workspace`。编译设置放在源文件夹外，源文件夹仍只保留tex、bib和图片。
2. 打开 `sjj22627171/sjj22627171.tex`，修改和保存，或按 `Ctrl+Alt+B`。
3. 完整编译方案名为 **XeLaTeX + Biber (latexmk)**。`latexmk`会根据需要运行XeLaTeX、Biber，再重复XeLaTeX直至引用稳定。
4. 最新PDF和临时文件统一输出到 `build/sjj22627171/`。PDF为 `build/sjj22627171/sjj22627171.pdf`。在VS Code中执行 **LaTeX Workshop: View LaTeX PDF file** 可打开预览。

当前仓库窗口与打开20261020目录的窗口也已配置相同编译方案。若单独打开源文件夹且没有载入外面的工作区配置，可在终端使用以下命令。

## PowerShell命令

在 `sjj22627171` 源文件夹中运行：

```powershell
$env:LC_ALL = 'C'
$env:LANG = 'C'
latexmk -norc -xelatex '-outdir=../build/sjj22627171' sjj22627171.tex
```

输出路径参数整体加引号，避免PowerShell将带相对路径的参数拆开。

如需手动确认完整链路，可在同一目录运行：

```powershell
xelatex '-output-directory=../build/sjj22627171' sjj22627171.tex
biber --input-directory ../build/sjj22627171 --output-directory ../build/sjj22627171 sjj22627171
xelatex '-output-directory=../build/sjj22627171' sjj22627171.tex
xelatex '-output-directory=../build/sjj22627171' sjj22627171.tex
```

通常使用第一条latexmk命令即可，不需要手工管理这些步骤。

## 引用键显示异常的原因

原来的日志包含 `No file main.bbl`、17条 `Citation ... undefined`，以及 `Please (re)run Biber`。原文件头的 `% !TEX program = xelatex` 会使LaTeX Workshop优先使用单次XeLaTeX，绕开已经设置的latexmk方案，因此出现文献键而非数字引用。

新文件已移除这条program注释。`\printbibliography[title={参考文献}]`继续保留，文献库改为 `\addbibresource{reference.bib}`；不要用BibTeX程序替代本项目要求的Biber。

依据：[LaTeX Workshop官方编译说明的Magic comments部分](https://github.com/James-Yu/LaTeX-Workshop/wiki/Compile#magic-comments)。
